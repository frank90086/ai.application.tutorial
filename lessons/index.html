AI 應用工程師 8 週課程

八週後交出一個部署上線、附評估數據的金流情境 AI agent，以及五個核心能力：LLM API、RAG、Agent、Evals、安全合規。每兩週一個里程碑，所有程式碼疊加在同一個 repo 裡。

標準版 每週約 10 小時 衝刺版 每週約 20 小時 語言 Python 3.12

畢業專題：金流異常處理助手

客服人員用自然語言問交易問題，agent 查交易、查文件、擬回覆，遇到退款先等人核准。選這個題目是因為它正好用到金流背景——錯誤碼、對帳、退款風險這些細節，是一般 AI 作品集很少有的。

第 1–2 週 · 基本功
  • W1

    LLM API 基本功

    Messages API 結構、structured output 與 Pydantic 驗證、streaming、token 計價與成本量測、錯誤重試。含 Python 語法速成。

    產出：llm-basics repo + 三模型比較表 · 約 8–10 小時
  • W2

    Tool calling 與 Prompt 設計

    SQLite 假交易資料、手寫 tool-use 迴圈（不靠框架）、system prompt 當合約寫、prompt caching、MCP server。

    產出：查交易對話機器人 + MCP server · 約 10–12 小時
第 3–4 週 · 檢索與第一批評估
  • W3

    RAG 基礎

    Docker 起 Postgres + pgvector、文件切塊策略與「失去上下文」問題、embedding 模型選擇、帶引用的回答。包成第三個工具接到第 2 週的機器人。

    產出：文件問答 v1 + 檢索失敗案例筆記 · 約 10–12 小時
  • W4

    RAG 進階與第一批 Evals

    30 題黃金測試集與負面案例、recall@k 與 MRR、hybrid search 與 RRF 融合、rerank、faithfulness judge 與人工校準。

    產出：評估對照表 + 可重跑的 eval 腳本 · 約 10–12 小時
第 5–6 週 · Agent 與可觀測性
  • W5

    Agent 與工作流

    何時該用 agent、何時寫死就好；LangGraph 的 state / reducer / 條件分支；interrupt 人工核准與 checkpoint 中斷恢復；與手寫迴圈的比較。

    產出：Agent v1 + 流程圖 · 約 10–12 小時
  • W6

    Evals 與可觀測性

    自架 Langfuse 做 tracing、20 個端到端情境（含應拒絕與應轉人工）、pytest 回歸測試分層、GitHub Actions、p95 延遲與成本、用數據決定換模型。

    產出：Trace 截圖 + CI 徽章 + 換模型決策紀錄 · 約 10–12 小時
第 7–8 週 · 安全、部署與求職
  • W7

    安全、合規與部署

    OWASP LLM Top 10 2026、間接 prompt injection 與 10 種紅隊手法、Luhn 卡號遮罩、退款金額分級與稽核日誌、FastAPI + Docker 部署、金管會六大原則對照。

    產出：demo 網址 + 紅隊結果 + 合規對照頁 · 約 12–14 小時
  • W8

    收尾與求職準備

    README 的五分鐘法則、3 分鐘 demo 腳本、技術文章選題、把金流經驗重新框架的履歷寫法、六題面試題的答題素材。

    產出：完整作品集 + 新版履歷 · 約 10–12 小時

關於教材裡的 API 資訊

Claude 的模型 ID、價格與參數對照 2026 年 9 月的官方 SDK 文件，MCP 的部分對照 modelcontextprotocol.io 官方教學。LLM API 這兩年變動很大——網路上 2024–2025 年的教學有不少參數已經會直接回報 400 錯誤（例如 temperature）。開始每週前先確認官方快速入門有沒有更新。
